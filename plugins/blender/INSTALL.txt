VGS 4D Gaussian Splatting Player for Blender - installation
===========================================================

Plays VGS 4D Gaussian splat captures (.vgs, .pgs) in Blender.
Windows 64-bit, Blender 5.3 or later.

File: vgs-<version>.zip  (do not unzip it)

1. Open Blender.
2. Edit > Preferences > Get Extensions.
3. Click the arrow menu at the top right and choose "Install from Disk...".
4. Select vgs-<version>.zip and click "Install from Disk".
   (Dragging the zip onto Blender's window does the same.)
5. Make sure "VGS 4D Gaussian Splatting Player" is enabled in the list.

Use it: File > Import > VGS (.vgs, .pgs), or drag a .vgs file onto the 3D viewport.
The controls of each capture are in Properties > Data > VGS.

Distribution: the capture's VGS panel has a sample of laying copies of it out.
Select an object whose points should get copies (a mesh, a point cloud), then the
capture, so it is active, and press Sample: Scatter on Points. Each point gets a copy
at one of a few timelines, turned at random; everything is then set on the object's
VGS Scatter modifier. It is a sample - build your own distribution as you like.
Object > Remove VGS Scatter takes it off again.

To update: install the new zip the same way; restart Blender afterwards.
To remove: Edit > Preferences > Get Extensions, find it, and choose Uninstall.
