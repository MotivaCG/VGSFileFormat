# nanoflann

The header was copied from SMNForge's Dependencies/win64/nanoflann.
Purge Isolated adapts the Nth-neighbour/upper-median rule from
SMNForge's PlyGaussianSplatting::pruneIsolation. No OpenMP or SMNForge runtime
dependency is required. The original BSD copyright and license are retained in
nanoflann.hpp and LICENSE.txt.
