# Gracia Converter assets

Unmodified copies from
`D:/Trabajos/THE4DSCANNER/GraciaConverter/Gracia4DGSConverter`, copied on 2026-10-07
at the project owner's request. These are local resources; the editor does not
load graphics from the converter checkout at runtime.

- `logo.png`, `logo.ico`: application icon, shared with the converter. Replaced in both
  on 2026-10-20 with renders of the project's `logo.svg` (on white, full frame). Still the
  viewer's icon.
- `logo_vgs.png`, `logo_vgs.ico`: the VGS editor's icon, the green `logo_green.svg`;
  `logo_sgs.png`, `logo_sgs.ico`: the SGS editor's, the red `logo_red.svg` (2026-11-17,
  rendered as `logo.png`: on white, the logo over about 88 % of the square).
- `logo_bbb.svg`: legacy converter logo, retained for future use.
- `calib.png`, `calibtotem.png`, `range.png`: converter tool illustrations.
